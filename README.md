# Gender Bias in German Word Embeddings

Empirical project for the University of Trier NLP research poster.

## Research question
To what extent can gender-associated bias in German word embeddings be reduced through post-hoc debiasing while preserving semantic information?

## Core models
1. German Word2Vec (GermanWordEmbeddings / Müller)
2. German FastText (official fastText German Common Crawl + Wikipedia vectors)

Optional: German GloVe if time/resources permit.

## Experimental pipeline
1. Verify model vocabulary coverage.
2. Run baseline WEAT tests.
3. Estimate a German gender direction from definitional pairs.
4. Apply hard debiasing.
5. Apply soft debiasing.
6. Re-run bias metrics.
7. Evaluate semantic preservation.
8. Compare results and document limitations.

## Important
No results are hard-coded. All reported results must be generated by the experiment.
